# Picxo
Picxo was supposed to be a free and open source alternative to Flipnote but unfortunately it became too complicated for me so I'm making it open source anyway in case anyone wants to improve it because you never know.

# UPDATE 2026

Picxo is now under license CC0 1.0



# Why did I decide to release it under a Public Domain license?

Because it was one of my early Python projects that remained unfinished, I felt it deserved a place in the public domain. I will also use it as a list for the kits I have created, as I think it could be used as a Python script creation kit.
