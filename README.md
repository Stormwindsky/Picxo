## Picxo: Open-Source Pixel Art Scripting Kit

Picxo is a professional-grade Python scripting kit for creating grid-based pixel art and frame-by-frame animations. This tool offers a lightweight engine for canvas rendering, real-time animation management, and high-fidelity image export.
🛠 Features

    Dynamic Grid Engine: Complete control over pixel scaling and canvas dimensions via a tkinter interface.

    Animation Suite: Native support for multi-frame projects with instant frame-switching.

    Onion Skinning: Professional ghosting effect (Key: 1) to visualize the previous frame for precise animation.

    Export Pipeline: PicxoMp4.py utility converts raw grid data into rasterized PNG images using the Pillow engine.

    Data Persistence: Efficient save/load system using structured .txt color maps.

## 🏗 Installation & Usage

    Install Dependencies:
    Bash

    pip install Pillow

    Run Editor: Execute python Picxo.py.

    Animate: Use Left/Right arrows to navigate frames.

    Export: Use PicxoMp4.py to generate your final image files.
